# PTESCAN Tool

PTESCAN es una herramienta de descubrimiento y enumeración muy sencilla de usar, pero también muy rudimentaria para poder utilizar en esa fase de la metodología PTES de enumeración.

Permite hacer las siguientes tareas:

Descubrimiento:

- ARP Ping
- TCP Ping
- ICMP Ping
- UDP Ping

Enumeración de puertos:

- SYN Scan
- TCP Scan
- ACK Scan
- UDP Scan (experimental)

Obtener información:

- OS Discover
- Banner Grabbing
- Cabeceras HTTP
